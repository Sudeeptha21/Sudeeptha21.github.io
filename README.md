# Sudeeptha Sivarajan — Portfolio

Personal portfolio website built with React + Vite. Showcases my work as a Strategic Operations Manager with a background in data analytics and product thinking.

## 🔗 Live Site
[sudeeptha21.github.io](https://sudeeptha21.github.io)

## 🛠 Tech Stack
- **React 19** + **Vite**
- **React Router** — multi-page routing
- **Framer Motion** — animations
- **Lucide React** + **React Icons** — iconography

## 📁 Structure
```
src/
├── components/
│   ├── Navbar.jsx
│   ├── Hero.jsx
│   ├── About.jsx
│   ├── Projects.jsx
│   ├── Experience.jsx
│   └── Footer.jsx
├── pages/
│   ├── Home.jsx
│   └── ProjectDetails.jsx
└── data/
    └── projects.js
```

## 🚀 Running Locally
```bash
npm install
npm run dev
```
